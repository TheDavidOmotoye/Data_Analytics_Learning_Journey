# 📘 Day 1 Study Note — Types of Data

## 🎯 Objective
Understand different types of data and classify dataset columns correctly.

---

## 🧠 Key Concepts

Data can be grouped into:

## 1️⃣ Qualitative Data (Categorical)
These are descriptive values or labels.

Examples:
- Gender
- Department
- Employment Type

### Types of Qualitative Data
- Nominal: No order (e.g., Gender)
- Ordinal: Has order/ranking (e.g., Low, Medium, High)

---

## 2️⃣ Quantitative Data (Numerical)
These are measurable numeric values.

Examples:
- Salary
- Age
- Projects Completed

### Types of Quantitative Data

### 🔹 Discrete Data
Whole numbers only.

Examples:
- Number of projects
- Number of students

### 🔹 Continuous Data
Can take any value within a range.

Examples:
- Salary
- Height
- Weight

---

## 📌 Important Notes

✅ IDs are labels, not calculations.

✅ Dates are special data types used for time analysis.

✅ Quantitative data supports mathematical operations.

✅ Qualitative data is mainly used for grouping and categorization.
