# 🧩 Day 1 — Data Types & Classification

## 📘 Objective
Understand how data is classified and why proper identification of data types is essential before analysis.

---

## 📚 Concepts Covered
- Qualitative vs Quantitative Data
- Nominal vs Ordinal Data
- Discrete vs Continuous Data

---

## 🛠 Analysis Performed
- Classified dataset variables into appropriate data types
- Distinguished between categorical and numerical variables
- Applied data-type reasoning to business-oriented examples

---

## 💡 Key Insights
- Correct data classification determines the analytical methods available for each variable.
- Numerical variables can be further segmented into discrete and continuous forms for deeper analytical precision.
- Proper data typing is foundational to statistical analysis and dashboard design.

---

## 🎯 Key Takeaway
Accurate data classification is the first step in every analytical workflow and directly impacts analytical quality.
