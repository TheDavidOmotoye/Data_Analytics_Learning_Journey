# 📊 Day 8 — Data Visualization Principles

## 📘 Objective
Learn how to select the correct chart type based on analytical objective and data structure.

---

## 📚 Concepts Covered
- Line Charts
- Bar Charts
- Histograms
- Chart Selection Framework
- Visualization Best Practices

---

## 🛠 Analysis Performed
- Created line chart for monthly sales trend
- Built bar chart for category sales comparison
- Generated histogram for order value distribution
- Interpreted each visual for business insight

---

## 💡 Key Insights
- Electronics generated the highest annual sales among product categories.
- Sales trended upward steadily across all categories over time.
- Most order values clustered within lower-to-mid transaction ranges.

---

## 🎯 Key Takeaway
Choosing the correct visualization is essential for accurately communicating analytical findings.
