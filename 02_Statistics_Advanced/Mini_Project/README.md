# 📊 Advanced Statistical Analysis Mini Project

## 📌 Project Overview

This mini project was designed to simulate a real-world business analytics environment using a professionally structured dataset.

The project combines:
- statistical analysis,
- predictive modeling,
- forecasting,
- diagnostics,
- and business interpretation

to help strengthen practical data analytics skills using Microsoft Excel and advanced statistical techniques.

This project serves as a comprehensive portfolio-ready case study covering the major concepts learned during **Phase 2 — Advanced Statistical Analysis**.

---

## 🎯 Project Objectives

The objectives of this project are to:

✅ Apply advanced statistical analysis techniques to business data

✅ Perform hypothesis testing and statistical inference

✅ Analyze relationships between business variables

✅ Build regression and forecasting models

✅ Evaluate model reliability using diagnostics

✅ Interpret business trends and operational behavior

✅ Strengthen Excel analytics and visualization skills

✅ Develop portfolio-quality analytical reporting

# 📂 Dataset Description

The dataset contains simulated business and operational data including:

| Column | Description |
|---|---|
| Employee_ID | Unique employee identifier |
| Department | Employee department |
| Region | Business location |
| Gender | Employee gender |
| Training_Group | Training participation status |
| Month_No | Monthly observation period |
| Marketing_Spend | Advertising expenditure |
| Website_Traffic | Website visitors generated |
| Sales_Calls | Number of sales calls |
| Sales_Revenue | Revenue generated |
| Customer_Orders | Customer order volume |
| Employee_Satisfaction | Satisfaction score |
| Attrition | Employee resignation status |
| Project_Status | Project completion outcome |
